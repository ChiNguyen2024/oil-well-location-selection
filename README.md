# Выбор локации для бурения нефтяной скважины — «ГлавРосГосНефть»

ML-модель и Bootstrap-анализ для определения оптимального региона бурения с оценкой прибыли и рисков.

## Данные
- **Источник:** компания «ГлавРосГосНефть»
- **Охват:** три региона, 100 000 месторождений в каждом
- **Признаки:** три геологических признака (f0, f1, f2), объём запасов нефти (product, тыс. баррелей)

## Ход работы
- Первичный анализ данных: распределение запасов нефти по регионам, проверка дубликатов
- Обучение модели линейной регрессии для каждого региона, оценка качества (RMSE)
- Расчёт минимального объёма для безубыточной разработки
- Bootstrap-анализ (1000 итераций): распределение прибыли, 95% доверительный интервал, оценка риска убытков
- Финальный выбор региона на основе критерия риска < 2.5%

## Ключевые выводы

| Регион | Средняя прибыль (тыс. руб.) | 95% ДИ (тыс. руб.) | Риск убытков | RMSE |
|--------|-----------------------------|--------------------|--------------|------|
| 1 | 405 254 | –81 207 – 920 424 | > 2.5% | 37.76 |
| 2 | **436 213** | **10 956 – 815 993** | **< 2.5%** | 0.89 |
| 3 | 371 650 | –155 335 – 875 847 | > 2.5% | 40.15 |

- **Регион 2** — единственный с риском убытков ниже допустимого порога (2.5%) и наибольшей средней прибылью
- Регионы 1 и 3 отклонены из-за отрицательных границ доверительных интервалов
- Минимальный объём для безубыточности — 111.11 тыс. баррелей; средние значения по регионам ниже этой отметки, что подтверждает необходимость модельного отбора скважин
